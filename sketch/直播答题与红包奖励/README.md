- [双手机展示.png](双手机展示.png)：1239 × 1152 展示预览。
- [答题页.png](答题页.png) / [奖励弹窗.png](奖励弹窗.png)：各 780 × 1512 两倍界面预览。

## 画板与图层

| 画板 | 尺寸 | 内容 |
| --- | --- | --- |
| 01 · 直播答题页 | 390 × 756 | 视频封面、播放控制、直播标签、单选/多选题、滚动列表、活动说明与底部答题入口 |
| 02 · 红包奖励弹窗 | 390 × 756 | 直播背景、遮罩、奖励插画、答对 30 题、¥1.00 红包、获奖详情、查看答案和关闭按钮 |
| 03 · 双手机展示排版 | 1239 × 1152 | 两台手机外壳、圆角屏幕裁切、阴影和原生界面副本 |

所有图层均解锁。全文件含 **142 个原生 Text、431 个原生形状图层、29 个分组**。其中两个独立界面共有 71 个文字图层，展示画板另有 71 个文字副本。文字、题目选项、按钮、图标、红包、装饰、手机外壳均可独立修改，没有整页截图或位图图层。展示画板和独立界面为独立副本，修改其中一个不会自动同步到另一个。

原图模糊的视频封面、直播背景、小头像和红包插画使用原生矢量重新绘制，细节并非像素级复刻。页面为静态设计，没有连接实际直播、答题或红包业务。

使用 **Noto Sans CJK SC Regular / Bold** 字体（[官方字体仓库](https://github.com/notofonts/noto-cjk)）。在 macOS Sketch 中打开后可以直接修改文字、颜色、大小、位置和图层结构；如缺失字体，先安装字体，或替换为苹方/思源黑体后复核排版。

## 验证与复现

已通过 Sketch 官方文件格式 Schema、ZIP 完整性、画板尺寸、图层 ID、共享文字样式引用和圆角/滚动蒙版结构检查；142 个文字图层已检查宽度，无溢出。

PNG 是从交付 `.sketch` 实际 JSON 图层重新读取后，由 Chromium 绘制的检查预览。**尚未在 macOS Sketch 中实际打开、保存或原生渲染验证。**

在仓库根目录执行：

```bash
python3 'sketch/直播答题与红包奖励/生成设计稿.py'
python3 'sketch/直播答题与红包奖励/导出检查预览.py'
XDG_CACHE_HOME=/tmp/sketch-cache node 'sketch/直播答题与红包奖励/渲染预览.js'
python3 'sketch/直播答题与红包奖励/验证设计稿.py' --schema-dir /tmp/sketch-tools/node_modules/@sketch-hq/sketch-file-format/dist
```

生成器使用 Python 标准库并读取同仓库 `sketch/会员中心/会员中心.sketch` 的格式模板，不修改该模板。检查依赖 Pillow、jsonschema、Playwright 与系统 Chromium。Schema 可用 `npm install --prefix /tmp/sketch-tools --ignore-scripts @sketch-hq/sketch-file-format@6.5.0` 安装。运行生成器会覆盖本目录生成文件，请先保存自己的编辑副本。
